## Reporting a bug

1. Search [existing issues](../../issues?q=is%3Aissue) first. Add a thumbs-up to an existing report instead of opening a duplicate.
2. Update to the latest version of the mod and of Stope.
3. Open a [new issue](../../issues/new/choose) and pick the form for the mod.
4. Upload your `latest.log` (and crash report, if any) to [mclo.gs](https://mclo.gs) and paste the link.

## Labels

| Label | Meaning |
| --- | --- |
| `TrailWright`, `Strength In Numbers`, `Stope` | Which mod the issue is about |
| `bug` | Something is broken |
| `enhancement` | Feature request |
| `compat` | Conflict or interaction with another mod |
| `fabric`, `forge` | Happens only on that loader |
| `needs-triage` | Not yet reviewed |
| `confirmed` | Reproduced by the developer |
| `wontfix`, `duplicate`, `invalid` | Closed without a change |
